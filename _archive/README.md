# Archive

Salvaged reference material from the original Jupyter Book draft of this book
(formerly the separate `ai_in_action_old` working folder, which had no git
history and has since been removed). Kept here for reference only.

This folder name starts with `_`, so Quarto ignores it during render, nothing
here is part of the published book.

## Contents

- `notebooks/`, build-an-LLM-from-scratch notebooks (tokenization, sliding
  window, token & positional embeddings, attention weights) plus a grokking
  experiment.
- `04-08-attention-mech.md`, `04-10-attention-weights.md`, companion writeups
  for the attention notebooks.
- `gnn.md`, graph neural networks overview (GraphSAGE, PinSAGE, etc.).
- `bus-route-example/`, standalone applied optimization example (bus-stop
  placement) with data, report, and rendered maps.
